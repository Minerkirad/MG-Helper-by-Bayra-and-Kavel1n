## Подпись

Файлы подписаны самоподписанным сертификатом (`assets\certs\mghelper-selfsigned.cer`),
поэтому на чистой машине SmartScreen покажет «Windows защитила ваш ПК» — это ожидаемо.
Подпись Valid у всех четырёх артефактов; UAC при установке не запрашивается
(установка per-user). Для установки без предупреждений нужен доверенный сертификат:
см. docs\SIGNING.md.

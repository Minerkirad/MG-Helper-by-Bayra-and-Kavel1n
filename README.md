# MG Helper

**by Bayra & Kavel1n** · [Скачать последнюю версию](https://github.com/Minerkirad/MG-Helper-by-Bayra-and-Kavel1n/releases/latest)

Хелпер для GTA V + лаунчер Majestic RP + мод Miami Graphics.
Твои настройки графики больше **не слетают** после каждого запуска игры.

---

## Что делает

| Когда | Что происходит |
|---|---|
| Запуск лаунчера Majestic | Ванильный бэкап Majestic архивируется → графика MG не затирается |
| Запуск GTA 5 | Применяется твой эталон настроек графики |
| Каждый запуск | Снапшот настроек MG + архивация мелкого кэша |
| Выход из игры | Всё возвращается в исходное состояние |

> Никаких ручных действий после установки. Работает вместе с Windows.

## Установка

1. Один раз запустить и зайти в **Majestic + GTA V**
2. Скачать ZIP из [релизов](https://github.com/Minerkirad/MG-Helper-by-Bayra-and-Kavel1n/releases), распаковать
3. Запустить **MG-Helper.bat** → пункт **[1] Установка**

Готово. Дальше — просто играй.

## Возможности

- 🛡 **Защита настроек** — эталон применяется при каждом запуске игры
- 🔄 **Самовосстановление** — после выхода всё возвращается как было
- 🎨 **Профили** — MAX FPS и вырезание теней одной кнопкой
- 🔍 **Умный поиск** — сам находит GTA V / MG / Majestic на любом ПК (Steam, Epic, OneDrive, перенесённые папки)
- 📋 **Диагностика с выводами** — отчёт-файл готов к отправке, сам открывается в Проводнике
- 🛠 **Repair** — исправление типовых проблем одной кнопкой
- ⬆ **Проверка обновлений** — меню само сообщит о новой версии

## Файлы пакета

| Файл | Назначение |
|---|---|
| `MG-Helper.bat` | меню (всё управление отсюда) |
| `1-install.bat` | установка |
| `2-reset-settings.bat` | сделать текущие настройки защищёнными |
| `3-import-settings.bat` | импорт готового settings.xml |
| `max-fps.ps1` / `cut-shadows.ps1` | профили производительности |
| `4-clean-cache.bat` | очистка кэша Majestic (по необходимости) |
| `5-diagnose.bat` | диагностика + отчёт |
| `0-uninstall.bat` | удаление |

## Если что-то не работает

Запусти **MG-Helper.bat → [7] Диагностика**.
Она сама определит проблему и создаст `report_*.txt` — пришли его автору.

## Важно

- У каждого свои настройки — пакет не переносит чужие
- Разрешение экрана и видеокарта не трогаются никогда
- Автоматика ничего не удаляет — всё архивируется в `%LOCALAPPDATA%\MG_Helper`
- **Дисклеймер**: пакет не связан с Majestic RP и Miami Graphics. Использование на свой риск — правила лаунчеров могут меняться

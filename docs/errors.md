# Коды ошибок MG Helper (MG-E-XXXX)

Коды появляются в watcher.log, событиях и сообщениях. Приложи `report_*.txt`
(Диагностика [8]) вместе с кодом.

| Код | Где | Значение | Что делать |
|---|---|---|---|
| MG-E-0101 | watcher | state.json не сохранился | Проверь диск/антивирус; adopt-защита может сброситься — перезапусти watcher [9] |
| MG-E-0102 | watcher | pre-apply бэкап не создан | Настройки при старте НЕ перезаписываются (защита сработала). Проверь антивирус |
| MG-E-0103 | watcher | FileSystemWatcher недоступен | Guard работает по polling; уведомь автора |
| MG-E-0104 | watcher | эталон не записан (файл занят/эталон нечитаем) | В `events.jsonl` рядом лежит `apply.failed` с причиной. Закрой игру и повтори, либо Repair [9]; если повторяется — пришли отчёт [8] |
| MG-E-0201 | watcher | .bin восстановлены частично | Риск 1002 при запуске Majestic; след. тик докопирует, проверь `vanilla_backup_archive` |
| MG-E-0202 | watcher | .bin восстановить не удалось | Запусти Repair [9]; проверь место на диске |
| MG-E-0301 | watcher | Ключ эталона не совпадает (игра/GPU сменились) | Меню [11] — создать новый эталон; watcher перезапускается сам |
| MG-E-0401 | профили | Второй файл не записан | Эталон откачен из бэкапа; запусти профиль ещё раз после разблокировки |
| MG-E-0402 | профили | Откат не подтверждён | Восстанови эталон вручную из `before_*` бэкапа или История эталона [13] |
| MG-E-0501 | uninstall | Watcher всё ещё запущен | Закрой powershell-процессы с `gta-settings-watcher` в командной строке |
| MG-E-0502 | uninstall | Автозапуск удалён не полностью | Проверь планировщик задач и Run-ключ |
| MG-E-0503 | uninstall | .bin восстановлены частично | Риск 1002; запусти Majestic — недостающие докопируются, либо Repair [9] |

## SAFE MODE: что это и как выглядит

SAFE MODE — это честное «сейчас не защищаю»: watcher работает, видит игру, но
не применяет эталон и не усыновляет изменения, чтобы не затереть настройки,
которые он не может проверить.

| Причина | Событие в `events.jsonl` | Что видит пользователь |
|---|---|---|
| ключ эталона не совпал: сменилась игра (V → Enhanced) или видеокарта/драйвер | `golden.mismatch` + `session.unknown` (код MG-E-0301) | жёлтая иконка «SAFE MODE: защита выключена», баллун «Сменилась игра/GPU — создай новый эталон (меню [11])» |
| игра уже запущена, а `state.json` не доверенный (перезапуск watcher'а/Repair во время игры) | `session.unknown` | жёлтая иконка «SAFE MODE: защита выключена»; после закрытия игры watcher сам возвращается в обычный режим |
| `status=stopping` или heartbeat старше 30 с | — | красная/серая иконка «Watcher не работает (меню [9])» |
| health-файл битый | — | жёлтая иконка «Статус неизвестен» |

Что видно в файлах: `watcher.health.json` → `phase: "UnknownSession"` при
запущенной игре; `events.jsonl` → `session.unknown` с причиной. Диагностика [8]
показывает статус watcher'а по свежести heartbeat и сравнивает живой
`settings.xml` с эталоном, поэтому «Всё в порядке» печатается только когда
проверки действительно пройдены.

Выход из SAFE MODE по ключу: меню [11] — создаёт новый эталон по текущей игре
и GPU и перезапускает watcher, чтобы тот перечитал эталон и ключ. [9] Repair
перезапускает watcher и без нового эталона. Закрытие игры выход из SAFE MODE не
заменяет: эталон, снятый на другой игре или видеокарте, всё равно нужно
пересоздать.

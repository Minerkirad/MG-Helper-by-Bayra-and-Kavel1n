# Переносимость: чтобы работало на любой машине

Проверяется тестом `tools\integration-portability.ps1` (входит в `tools\check.ps1`).

## Что уже работает независимо от машины

| Условие | Что делает MG Helper |
|---|---|
| Нет WebView2 Runtime | Приложение стартует в **упрощённом режиме**: окно со статусом watcher'а, кнопки «Скачать WebView2», «Открыть папку», «Диагностика». Защита при этом не зависит от UI — watcher работает отдельно |
| Путь с пробелами и кириллицей (`%USERPROFILE%` с русским именем) | Все пути строятся от `%LOCALAPPDATA%`/`$PSScriptRoot`, кавычки в вызовах везде обязательные; установка проверена в каталоге вида `%TEMP%\MG Helper портатив <id>` |
| Нет прав администратора | Установка per-user (`PrivilegesRequired=lowest`), UAC не запрашивается. Если `schtasks` недоступен — `install-3.1` создаёт ярлык в автозагрузке; watcher поднимается при входе |
| Другой пользователь Windows | Всё в его профиле; чужие данные не читаются |
| DataRoot не по умолчанию | Переопределяется `MG_HELPER_DIR` (используется тестами и портативным режимом), канал становится `MG_Helper_test` |
| GTA V/лаунчер в другом месте, OneDrive-Documents | Пути ищутся обнаружением (Steam/Epic/Rockstar, OneDrive), config хранит найденное |
| Нет Miami Graphics / Majestic | Соответствующие функции отключаются, остальное работает |
| Windows 10/11 x64, PowerShell 5.1 | Целевая платформа; приложение net48 + WebView2, скрипты 5.1 |
| Нет интернета | Отчёты не уходят (остаются в папке), обновление не проверяется, защита работает |

## Самоотчёт об окружении

`MGHelper.exe --env` пишет `ui-env.json`: версия ОС, наличие и версия WebView2, режим
(обычный/упрощённый), DataRoot и его доступность на запись, имя канала, наличие задачи
автозапуска, интерактивность сессии. Это первый файл, который нужен при разборе
проблемы на чужой машине.

## Урок про кодировки (уже исправлен)

PowerShell 5.1 без BOM читает файл как ANSI: кириллица в путях ломается. Поэтому:
- все `.ps1` в репозитории — **UTF-8 с BOM** (проверяется набором тестов);
- JSON, который читает PowerShell, пишется **с BOM** (`ui-env.json`), а тесты читают
  через `[IO.File]::ReadAllText` (явный UTF-8).

## Что осталось проверить

- машина без .NET Framework 4.8 (на Windows 10+ он есть, но на урезанных сборках — нет):
  установщик должен предупреждать, а не падать;
- Windows Server / сессия без интерактивного рабочего стола (трей и окно недоступны —
  watcher продолжает работать);
- антивирус, блокирующий неподписанный exe (снимается только доверенным сертификатом,
  см. `docs\SIGNING.md`);
- машина с уже установленной другой версией MG Helper (проверяется откат и миграция).

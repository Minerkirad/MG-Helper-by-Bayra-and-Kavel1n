## P1 — следующий спринт: удобство и надёжность

**Установка и обновление**
- Проверка обновлений в приложении (кнопка + автораз в сутки), скачивание с проверкой SHA256, откат из UI.
- Инкрементальная установка: не перезаписывать версию, если она совпадает (сейчас всё равно копирует).
- Устойчивость к антивирусу: retry + понятное сообщение, если файл удалён после установки.

**Приложение (полировка после вашего теста)**
- Онбординг первого запуска: что защищается, где эталон, как отключить автозапуск.
- Экран «Журнал»: фильтры по типу события, поиск, открытие в редакторе, копирование.
- Экран «Отчёты»: история отправок, повторная отправка, ссылка на последний отчёт.
- Настройки: тема (системная/тёмная/светлая), уведомления, порог охраны, автозапуск — всё переключается из UI.
- Действия: «новый эталон» с диффом «было → станет», «восстановление MG» с выбором поколения снапшота.
- Трей: меню со статусом и быстрыми действиями, индикация SAFE MODE.

**Релизный процесс**
- GitHub Actions: шаг подписи (готов как `docs/ci-signing-step.yml.txt`, нужен токен со `workflow`-scope).
- Автоматический релиз по тегу: сборка, подпись, ассеты, заметки из CHANGELOG.
- Проверка на чистой VM: Windows 10 + Windows 11 без WebView2 и без интернета (ручной чек-лист).

**Качество**
- Расширение parity: сценарии «смена железа», «чужой settings.xml до старта», «torn state».
- Интеграционный тест полного цикла установки через `Setup.exe /VERYSILENT` в песочнице (Inno ставится на раннере).

## Решения владельца (2026-11-28)

| Вопрос | Решение |
|---|---|
| Сертификат | **остаётся свой (self-signed)**: денег на покупку нет. Установщик добавляет наш публичный `.cer` в доверенные текущего пользователя (`certutil -user`, без админских прав), чтобы подпись была `Valid` на машине пользователя. SmartScreen может предупредить — это честно написано в README |
| Релей отчётов | аккаунт Cloudflare заведён (через Google). В репозитории лежит готовый воркер `relay/worker.js` и клиент `Send-MgReport`: приложение берёт URL из `config.json → reportUrl`. Остаётся задеплоить воркер и прислать URL |
| Дизайн | идём **по вкладкам по порядку**: Обзор → Отчёты → Журнал → Инструменты → Настройки (новый дизайн уже в 3.1: единая система, тёмная/светлая тема, тумблеры, чипы статуса, фильтры журнала) |
| Портативный режим | **не официальный**: продукт ставится одним `Setup.exe` на машину (свою, друга, любого пользователя), полностью — приложение, watcher, задача, автозапуск. ZIP остаётся только как архив исходников/сборки |
## Правила, которые не меняются

1. Инварианты защиты (эталон, adopt по желанию, охрана всей сессии, SAFE MODE виден,
   byte-exact эталон) — не ослабляются ни одной задачей.
2. Каждая задача заканчивается зелёными `tools\check.ps1` и `tools\parity.ps1 -Both`.
3. Пользовательские данные не перемещаются и не удаляются; любая запись — с копией.
4. Секция благодарностей в README и упоминания авторов не редактируются.
5. Артефакты релиза всегда подписаны; неподтверждённая подпись блокирует публикацию.
